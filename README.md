# DINO AI 基礎幾何（課程：中英文版、簡英文版）

DINO AI 數學「基礎幾何」，靜態網頁，用 GitHub Pages 發布。產生日期：2026-11-19。

## 頁面

| 網址路徑 | 內容 | 語言 | 登入 |
|---|---|---|---|
| `/` | 課程（中英文版） | 繁體中文＋英文，可切換 | 要 |
| `/cn.html` | 課程（簡英文版） | 简体中文＋英文，可切換 | 要 |

## 發布設定

1. Settings → Pages：來源選 `main` 分支、根目錄（`/`）。
2. 推上去後一兩分鐘內上線。網址是 `https://<帳號>.github.io/<儲存庫名稱>/`。

`.nojekyll` 讓 Pages 原樣發布檔案；`.gitattributes` 讓 git 不更動換行與音檔內容。兩個都不要刪。

## 內容

- `index.html`、`cn.html`：頁面本體。
- `audio/`：預錄語音 7536 個音檔（`cn`、`en`、`tw`）和索引 `index_tw.js`、`index_cn.js`，約 184 MB。頁面和 `audio/` 必須在同一層。
- `icon.png`：這個版本的圖示（備用；頁面用到的圖示已經放在頁面裡）。
- 語音全部是預錄音檔（Azure 語音），頁面不使用瀏覽器內建語音；找不到音檔的句子不會出聲。
- 檔名就是網址的一部分，上線後不要改名。

## 注意

- **登入只是擋一般使用者的門**：頁面沒有伺服器，帳號密碼在瀏覽器裡比對，不是真正的保護。
- **目前是測試版**：登入畫面預先填好帳號密碼，帳號密碼的原文在頁面裡。儲存庫若是公開的，任何人都看得到。正式上線前要關掉預填並重新產生。
- 這裡只放成品。來源檔、錄音工具、API 金鑰都不放進來。
- 音檔沒有逐句人工試聽；iPhone／iPad 尚未在實機上測試。
